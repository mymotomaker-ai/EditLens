# Changelog

All notable changes to EditLens are listed here. Versions follow [Semantic Versioning](https://semver.org/).

## 1.0.0 (release date)

First public release.

- Highlights each edit on the page, with the file and line
- Shows Claude's replies, tool steps, and subagents live in a panel on the page
- Shows each edit in a code view next to the page, with replay
- Sends messages and selected elements from the page to Claude
- Runs Claude from the page with page control
- Pairs two computers to see and control Claude on another computer
